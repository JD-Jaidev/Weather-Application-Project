# 🌤️ Weather Application

A simple desktop weather application built with **Python, PyQt5, and a Weather API**. It uses the `requests` library to fetch real-time weather information and displays it through a user-friendly GUI.

## ✨ Features

* 🌍 Search weather by city
* 🌡️ View temperature
* 💧 View humidity
* 🌬️ View wind information
* ☁️ View current weather conditions
* 🖥️ Simple PyQt5 GUI

## 🛠️ Technologies

* Python
* PyQt5
* Requests
* Weather API

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/JD-Jaidev/Weather-Application-Project.git
cd Weather-Application-Project
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

Or install them manually:

```bash
pip install PyQt5 requests python-dotenv
```

## 🔑 API Key

Add your Weather API key to the project as required by the application to the ```.env``` file.

## ▶️ Run the Application

```bash
python main.py
```
